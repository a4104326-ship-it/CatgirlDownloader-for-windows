# CatgirlDownloader for Windows

Windows port of NyarchLinux/CatgirlDownloader.

## Download

The compiled version for Windows is available in Releases:

https://github.com/a4104326-ship-it/CatgirlDownloader-for-windows/releases

## Usage

- Download the `.zip` or `exe installer` file.

- Extract the `zip` or run the `installer`.

- Run `CatgirlDownloader.exe` or if you used the `installer`, open the shortcut or search on your start menu.
